Установка

  1. Скачай установщик или распакуй полный ZIP. Перед обновлением закрой PeakMP3 и текущие загрузки.
  2. Запусти Setup.exe обычным способом. Программы устанавливаются в профиль пользователя без запроса прав администратора.
  3. Мастер подключения откроет страницу расширений выбранного браузера. Включи режим разработчика и выбери «Загрузить распакованное».
  4. Укажи папку extension, показанную мастером. Закрепи зелёную стрелку. После обновления перезагрузи само расширение, затем вкладку YouTube.

Обычный MP3 или звук с характером

Сохрани MP3 без обработки — или передай исходный AAC в PeakMP3. Программа откроет файл, чтобы ты мог прослушать результат, выбрать плотность и сохранить MP3.

Регулятор плотности и переключатель A/B помогают выбрать подходящий вариант. Папка по умолчанию — рабочий стол. При сохранении можно выбрать другую.

Windows 7 и слабые компьютеры

Обязательная цель — Windows 7 SP1, 32 бита и процессор с SSE2. Программы используют .NET Framework 3.5 / CLR2; на новых Windows предусмотрен запуск через CLR4. .NET 4.8 и WebView2 не требуются. Windows, браузер и системная среда .NET устанавливаются отдельно.

Пользователь подтвердил работу комплекта на Windows 11 с актуальным Chrome и Windows 7 с Яндексом и Chrome для этой системы. Точные версии браузеров и полный перечень выполненных сценариев пока не зафиксированы. Windows 10 отдельно не проверена.

Удаление и возврат версии

Удаление через приложения Windows убирает программу и интеграцию, сохраняя пользовательские файлы, настройки и аудиокэш. Расширение удаляется отдельно из каждого профиля браузера. Если имеется резервная копия, Restore_previous.cmd возвращает прежнюю установку.

Если что-то не получилось

Проверь, что в браузере загружено расширение 2.6.0 из установленной папки. Перезагрузи расширение и вкладку YouTube. Открой зелёную стрелку: там можно проверить связь с PeakMP3. В сообщении об ошибке укажи Windows, браузер, формат и точный текст отказа.

YouTube иногда требует подтверждение сеанса (attestation required). Такой отказ остаётся ограничением Preview; видео автоматически не включается.

Права и компоненты

Собственный код доступен для ознакомления; неизменённый выпуск — для личного использования. Сторонние лицензии действуют отдельно.
