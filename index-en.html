Before you startOriginally created for Windows 7 and low-powered computers. The native component targets .NET Framework 3.5 / CLR2, with configured CLR4 fallback for modern Windows. Windows 10/11 and compatible older/newer Chromium browsers are intended targets; see the exact test matrix.

Installation

The steps from “Installation” in the guide.

1. Download Setup or extract the complete ZIP; close PeakMP3 and active downloads
2. Run Setup.exe: installs into your user profile, no administrator rights
3. In the wizard open the extension manager: Developer mode, “Load unpacked”
%LOCALAPPDATA%\YTWin7_360_MP3\extension
4. Select the extension folder, pin the green arrow, reload the YouTube tab

Connection

The program and the extension run locally on your PC. Videos are downloaded straight from YouTube (googlevideo); there is no cloud service of its own.

Straight from YouTubeNo cloud service

Save MP3 without processing, or send original AAC to PeakMP3. The application opens the file so you can listen, adjust density and save your MP3.
