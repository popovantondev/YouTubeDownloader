YouTube Downloader

Любимое видео. Твой формат. Сохраняй видео и звук с YouTube. Показывай только те кнопки, которыми пользуешься.

Предварительная версия · 2.6.0 Windows 7 SP1 / 10 / 11 · x86 / x64
Скачать для Windows Исходный код C# · JavaScript Руководство ↗

Перед запускомПервоначально создан для Windows 7 и слабых компьютеров. Локальный компонент использует .NET Framework 3.5 / CLR2; для современных Windows предусмотрен запуск через CLR4. Рассчитан также на Windows 10/11 и совместимые старые/новые Chromium-браузеры. Реальные проверки перечислены отдельно.

01

Исходное качество

Видео и AAC сохраняются без перекодирования. Качество MP3 зависит от исходной дорожки.

02

Без просмотра

Загрузка по умолчанию идёт без включения видео. Способ работы меняется в настройках.

03

Три языка

Настройки, сообщения и инструкции доступны на русском, немецком и английском.

Что внутри

Установка, функции, передача данных и проверка.

Установка

Шаги из раздела «Установка» руководства.

1. Скачать установщик или распаковать полный ZIP; закрыть PeakMP3 и загрузки
2. Запустить Setup.exe: установка в профиль пользователя, без прав администратора
3. В мастере открыть страницу расширений: режим разработчика, «Загрузить распакованное»
%LOCALAPPDATA%\YTWin7_360_MP3\extension
4. Выбрать папку extension, закрепить зелёную стрелку, перезагрузить вкладку YouTube

Подключение

Программа и расширение работают локально на вашем ПК. Видео загружаются напрямую с YouTube (googlevideo); собственного облачного сервиса нет.

Только нужные кнопки

По умолчанию на YouTube видны быстрый 360p и MP3, а также исходные 480p и 720p. Остальные качества и AAC включаются по зелёной стрелке в браузере.

Обычный MP3 или звук с характером

Сохрани MP3 без обработки — или передай исходный AAC в PeakMP3. Программа откроет файл, чтобы ты мог прослушать результат, выбрать плотность и сохранить MP3.

PeakMP3 ↗
  • Исходный AAC без промежуточного MP3
  • Передача в очередь уже открытого PeakMP3
  • Прослушивание и сохранение под твоим контролем
