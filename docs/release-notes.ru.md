# 2.6.0 Preview + PeakMP3 0.16.0

## Изменения

Общий установщик YouTube Downloader 2.6.0 Preview и PeakMP3 0.16.0. MP3 без обработки либо передача исходного AAC в очередь PeakMP3 без автозапуска. RU/DE/EN, оформление сайта в кремовых тонах, дереве и металле; отдельная бесшумная демонстрация управления.

## Совместимость

Обязательная цель: Windows 7 SP1, 32 бита, SSE2, .NET 3.5 / CLR2; CLR4 на новых Windows. Локальные проверки выполнялись на Windows 11. Пользователь сообщил об успешной работе на Windows 11 с актуальным Chrome и Windows 7 с совместимыми Яндексом и Chrome (примерно 109); точные версии и полный набор сценариев не зафиксированы. Windows 10 отдельно не проверена. Подробности: CHECKS-260.md.

## Установка

Запустите общий Setup.exe без администратора или распакуйте полный ZIP. Перед обновлением закройте PeakMP3 и активные загрузки. Подключите распакованное расширение по мастеру отдельно в каждом профиле Chrome, Edge или Яндекса. Существующие ID, настройки и аудиокэш сохраняются.

## Ограничения

Preview: YouTube может отказать с attestation required; отказ не объявляется исправленным. Автоматического включения видео нет. Полная живая матрица браузеров/качеств, Windows 10 и агентский прогон Windows 7 остаются непроверенными. Синтетические медиатесты не подтверждают звучание музыки или точное совпадение VU с AIMP. DRM, Vimeo, другие сайты, эфиры и плейлисты не входят в выпуск. EXE без цифровой подписи.

## Контрольные суммы

Точные размеры и SHA-256 файлов опубликованы в public-release.json и SHA256SUMS.txt этого выпуска. Полный ZIP включает программу, исходники, FFmpeg/FFprobe, соответствующие исходники компонентов, лицензии и офлайн-инструкции.
