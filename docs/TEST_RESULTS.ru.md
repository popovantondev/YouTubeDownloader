# Результаты проверок — 2.5.0 Preview

Проверки выполнены на Windows 11; дата 15.10.2026.

- Chrome/Edge: настоящее меню RU/DE/EN, светлая/тёмная темы, клавиша Tab, начальные настройки, быстрые переключения, сохранение и обновление открытой страницы. Метаданные ролика в тесте интерфейса искусственные.

- Настоящая регистрация HKCU: оба браузера запустили неизменённый EXE выпуска и получили корректный ответ lookup. ID расширения и allowed_origins совпали.

- Установщик WSH с отдельным LocalAppData: обновление 2.4.2, полная копия медиакомпонентов, восстановление, повторная установка и удаление интеграции. Контрольный файл кэша сохранился. Прежние значения реестра после теста возвращены.

- Локальные медиаобразцы: 144/240/360/480/720/1080p H.264, копирование VP9 и AV1 без изменения пакетов; сохранность пакетов AAC/Opus; AAC из нового потока и кэша, MP3 320; длительность, высота, кодек, пропущенные/оборванные сегменты и очистка при отмене. Образцы создавались и полностью декодировались отдельным полным FFmpeg; проверяемый компонент использовал новые минимальные инструменты выпуска.

- Образцы SABR: разрыв заголовков UMP, многобайтные ID, повторная инициализация, время в тиках, сохранение контекста, ограничение буфера и точное совпадение дорожек. Повторы только того же качества, максимум три; отмена запрещает отложенный запуск. Тест медленной страницы ждёт 150 секунд и начинает после готовности.

- Реальная попытка Edge 480p (lyuFLU2Zqz0): часть данных получена, затем сервер потребовал attestation. Загрузка не завершилась. Видео осталось на паузе ровно на 5,51346 секунды до и после. Это зафиксированный отказ, а не успешный медиатест.

- Не проверены: чистая Windows 7 с 2.5.0, Windows 10, актуальный Яндекс и полная загрузка всех шести форматов с живого YouTube. Отчёты 2.4.2 относятся только к прежней версии.

- Сайт: проверены 24 сочетания языка, главной страницы/руководства, темы и размера экрана. Изображения загружаются, горизонтального переполнения нет; примеры просмотрены визуально.
- Смена настроек во время захвата: скрытие всех исходных качеств сохраняет задачу и доступную отмену.
- Все 17 полученных медиаобразцов полностью декодированы отдельно без ошибок.
