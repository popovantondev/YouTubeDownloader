YouTube Downloader

Ihr Video. Ihr Format. Videos und Audio von YouTube speichern. Nur die Schaltflächen anzeigen, die Sie wirklich brauchen.

Vorabversion · 2.6.0 Windows 7 SP1 / 10 / 11 · x86 / x64
Für Windows herunterladen Quellcode C# · JavaScript Anleitung ↗

Vor dem StartUrsprünglich für Windows 7 und schwache Rechner entwickelt. Die lokale Komponente zielt auf .NET Framework 3.5 / CLR2; für moderne Windows-Versionen ist CLR4-Fallback konfiguriert. Auch Windows 10/11 und kompatible ältere/neuere Chromium-Browser sind vorgesehen. Tatsächliche Tests sind getrennt aufgeführt.

Installation

Die Schritte aus „Installation“ in der Anleitung.

1. Setup laden oder das vollständige ZIP entpacken; PeakMP3 und aktive Downloads schließen
2. Setup.exe normal starten: Installation im Benutzerprofil, ohne Administratorrechte
3. Im Assistenten die Erweiterungsverwaltung öffnen: Entwicklermodus, „Entpackte Erweiterung laden“
%LOCALAPPDATA%\YTWin7_360_MP3\extension
4. Ordner extension wählen, grünen Pfeil anheften, YouTube-Tab neu laden

Verbindung

Programm und Erweiterung laufen lokal auf Ihrem PC. Die Videos laden sie direkt von YouTube (googlevideo); einen eigenen Cloud-Dienst gibt es nicht.

Einfaches MP3 oder mehr Charakter

MP3 ohne Bearbeitung speichern oder Original-AAC an PeakMP3 übergeben. Das Programm öffnet die Datei zum Anhören, Einstellen der Dichte und Speichern als MP3.

PeakMP3 ↗
  • Original-AAC ohne zwischenzeitliche MP3
  • Übergabe an die Warteschlange des offenen PeakMP3
  • Anhören und Speichern unter Ihrer Kontrolle

Ein Installationspaket, zwei Programme

Das Release v2.6.0 enthält ein gemeinsames Setup. Es installiert zwei Programme, jedes mit eigenem Repository und eigener Website.
